# CycloneX
LIVE LINK - https://cyclonex-zeta.vercel.app/



## About

CYCLONEX is an AI-driven tropical cyclone intelligence system focused on the automated identification, classification, and prediction of tropical cyclone patterns using multi-source satellite observations.

The system is designed around deep learning and spatiotemporal modelling to analyse atmospheric structures, understand cyclone evolution, estimate storm intensity, and predict potential trajectories. By combining satellite image analysis with predictive modelling and geospatial intelligence, CYCLONEX aims to support more informed cyclone monitoring and disaster preparedness.

## Intelligence Pipeline

**Satellite Data → Image Processing → Deep Learning → Temporal Analysis → Forecast Generation → Risk Visualization**

### Core Research Components

- **Satellite Intelligence:** Analysis of Visible, Infrared, and Water Vapour imagery.
- **Cyclone Pattern Recognition:** CNN-based extraction of spatial features and atmospheric structures.
- **Spatiotemporal Learning:** ConvLSTM-based modelling of cyclone development across sequential observations.
- **Intensity Estimation:** Modelling changes in cyclone strength using meteorological features.
- **Trajectory Forecasting:** Predictive analysis of potential cyclone movement.
- **Risk Intelligence:** Geospatial visualization of forecast tracks and potential impact zones.

## Technology

`Python` · `PyTorch` · `CNN` · `ConvLSTM` · `NumPy` · `OpenCV` · `Pandas` · `React.js`

## Mission

To develop an intelligent, data-driven framework for tropical cyclone pattern recognition and forecasting, contributing to advances in deep learning-based meteorological analysis and disaster-management decision support.
